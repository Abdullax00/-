# Калькулятор рассрочки

Интерактивный веб-калькулятор рассрочки с гибким расчётом скидки на наценку в зависимости от размера первоначального взноса.

## Возможности
- **Двусторонняя синхронизация**: управление через ползунки и текстовые поля.
- **Быстрые пресеты взноса**: 0%, 10%, 20%, 30%, 50%.
- **3 формулы расчёта скидки**:
  1. *Прямая скидка (пропорциональная)*: скидка растёт плавно и пропорционально размеру взноса.
  2. *Бонус за решительность (квадратичная)*: даёт ощутимую выгоду даже при небольшом взносе.
  3. *Ступенчатая шкала (уровни)*: фиксированные пороги выгоды при достижении ключевых сумм.
- **Адаптивный дизайн**: плавная работа на мобильных устройствах и десктопе, стильный стеклянный UI (glassmorphism).
- **Чистый стек**: Vanilla HTML5, CSS3, JavaScript (без внешних зависимостей и фреймворков).

## Демонстрация
Проект оптимизирован для работы на **GitHub Pages** (основной файл — `index.html`).
